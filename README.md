🐱‍👤 Pokémon Fetcher

A responsive Pokémon information app built using the JavaScript Fetch API.
This project was created to practice API integration, dynamic DOM manipulation, and to improve HTML and CSS styling skills.

📌 Features

Fetches Pokémon data from the PokéAPI

Displays Pokémon name, ID, image, and stats

Uses official Pokémon artwork for high-quality visuals

Real-time data rendering using JavaScript

Clean and responsive UI for mobile, tablet, and desktop

Simple and intuitive user interface

🛠️ Technologies Used

HTML5 – Structure

CSS3 – Styling and responsiveness

JavaScript (ES6) – Fetch API, DOM manipulation

PokéAPI – External Pokémon data source

🚀 How It Works

User enters a Pokémon name in the input field

JavaScript fetches data from the PokéAPI

Pokémon image, ID, and stats are dynamically rendered on the page

The UI updates instantly without page reload

📱 Responsiveness

Mobile-first design

Media queries used for different screen sizes

Scales smoothly across devices

🎯 Purpose of This Project

This project was built as a hands-on practice exercise to:

Understand how the Fetch API works

Learn how to handle API responses

Practice DOM manipulation using JavaScript

Improve UI styling with HTML and CSS

Gain confidence in building real-world frontend projects

No loading animation (future improvement)
